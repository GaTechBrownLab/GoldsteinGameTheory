# GoldsteinGameTheory

Reannimation of Goldstein game theory model and evolutionary simulations. 

# Project structure 

## 1. R file GoldsteinGameTheory_plots.Rmd

- Plots simulation results. 

## 2. Python file Jave_implementation_trial.py 

- Runs the simulations, saves the results to results and postproc folder. Adjust the directories to your own
and run in your convenient python environment. 

## Extras 

Original Java code from Goldstein called Simulate.java.
